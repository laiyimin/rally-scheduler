# 球局小幫手

把 LINE 群組的接龍訊息貼進來，自動抓出名字，選單打或雙打、場地數，就排好整場賽程，打球時直接在手機上記分。

## 功能

- **貼上接龍自動解析**：支援 `1.名字`、`1 名字`、`1、名字`、全形數字；空位、「滿額」會略過；`民16:15` 會辨識成 16:15 才到；`小明+1` 會多加一位朋友；「候補」之後的人預設不排。
- **排賽程**：單打 / 雙打、多面場地；每人上場數平均、避免連續休息、搭檔與對手盡量不重複；晚到的人到場前不會排到。
- **記分**：「現在」分頁只顯示這一輪，大按鈕加減分；打完自動換下一輪，並預告下一輪名單。
- **排名**：勝場 → 淨勝分 → 總得分 → 失分少者優先。
- **中途有人加入或離開**：保留已打的輪次，只重排剩下的。
- **分享**：一鍵複製文字賽程貼回 LINE 群組，或分享唯讀連結。
- **可安裝到手機主畫面（PWA）**，沒網路也能用；記分時螢幕不會自動鎖。

資料只存在這支手機的瀏覽器裡，不會上傳。

## 本機開發

```bash
node tools/serve.mjs        # http://localhost:5173
node --test test/*.test.mjs # 跑測試
node tools/make-icons.mjs   # 重新產生 PNG 圖示
```

純靜態網頁，沒有建置步驟，也沒有任何相依套件。

## 部署

推到 GitHub 後，`.github/workflows/pages.yml` 會自動跑測試並部署到 GitHub Pages。
第一次要在 repo 的 **Settings → Pages → Source** 選 **GitHub Actions**。
